# 0.3.2

审核通知编号化：编号通知在审核群之外同时投递到事件监听目标（管理员私聊、自定义群聊/私聊，可按“群邀请”“入群申请”开关关闭）；审批可引用任意一处收到的通知，或直接发送“同意 编号”，按协议消息 ID 定位、不从引用正文猜测。被自动审核处理的请求不再发空白摘要，监听目标收到一条自动处理结果。

权限模型统一：reviewers 即机器人管理员，可从私聊以“群管理 禁言 群号 @成员 10m”的形式跨群执行禁言、解禁、踢人、全员禁言；不要求操作者在目标群，但仍核验机器人角色，并受群管开关、管理范围与黑白名单约束。禁言/解禁/踢人支持一次多名成员，逐个核验、分别报告，豁免与角色保护逐目标生效。

事件通知具体化：成员加入区分受邀与申请通过；成员退出区分主动退出与被管理员移出（含操作人）；禁言变动带时长与操作人；撤回带发送者与操作人；管理员变动标注成员。

周期定时：定时禁言/解禁支持“每日22:00”“每周一09:30”写法，可带时区后缀（如 +08:00），缺省用服务器时区；到点执行一次后按规则重新排队，机器人离线期间到期的任务恢复后只补执行一次。

完整投票：新增反对票（达到阈值即否决，默认与通过票数相同）；投票禁言/踢人可用 `--禁言`、`--踢人` 单独开关；管理员投赞成立即进入执行、投反对立即否决；投票截止前 1 分钟群内提醒一次。

新增 12 项协议回归测试（私聊群管、多目标、编号审批、引用审批、监听群审批、事件详情、周期重排、反对票、管理员票、单独开关、到期提醒）；全套 119 项测试通过。
