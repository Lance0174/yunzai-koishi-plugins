# 0.3.0

群管默认所有群可用；投票、头衔和验证码默认可用。新增持久黑白名单（用户 / 全局 / 群）；黑名单忽略、白名单豁免。事件监听独立且默认开启，可发管理员或自定义群 / 私聊；事件通知指令开关并重启保留。保留旧数据库兼容。

包名从 ember-* 改为 yunzai-*。补齐原项目、原作者、迁移说明和许可证，并纳入每个 npm 安装包。

# 0.2.0

日常禁言/踢人/全员禁言直接执行，提供短指令；补齐角色/头衔、群资料、公告/精华、成员/禁言列表、批量解禁、排行/潜水清理、定时任务、自闭、名单、违禁词、投票、验证码、自动审核、文本路由和协议查询。持久化任务共用事务锁与执行认领标识，重启未知结果不重试。
