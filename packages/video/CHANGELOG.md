# 0.3.1

缺少 ffmpeg/ffprobe 时默认自动下载静态版到插件数据目录，无需手动执行 apk/apt 或开启 npm 安装脚本。已有工具直接复用；首次安装在后台进行，视频等待就绪后继续，安装耗时不占视频处理时限。支持下载重试、进度诊断、缓存完整性检查、损坏修复和卸载取消清理。

Linux x64/ARM64 使用无动态加载器的构建，适配 Alpine；Windows x64、macOS x64/ARM64 也提供对应下载。附 FFmpeg 与静态构建来源和原许可。

# 0.3.0

启动时检查 ffmpeg/ffprobe，缺失时在下载前报出安装方法；新增诊断。默认用群聊 / 私聊合并消息一次发送说明、封面和视频，保留普通发送选项。

包名从 ember-* 改为 yunzai-*。补齐原项目、原作者、迁移说明和许可证，并纳入每个 npm 安装包。
