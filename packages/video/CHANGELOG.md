# 0.3.4

修复 ffmpeg/ffprobe 下载中断后从零开始的问题：先保存压缩包，使用 Range / If-Range 断点续传，重启后保留进度；六次递增间隔重试并切换官方发布页与资产 API 入口。固定上游文件大小和 SHA256，完整校验后才解压和安装。服务器忽略 Range 时覆盖重下，文件变化或校验失败时清理损坏分片。为连接建立增加超时，同一数据目录内的插件实例串行安装。

视频继续普通发布；群管理仍为 0.3.1 开发预览，点歌仍为 0.3.0。

# 0.3.1

缺少 ffmpeg/ffprobe 时默认自动下载静态版到插件数据目录，无需手动执行 apk/apt 或开启 npm 安装脚本。已有工具直接复用；首次安装在后台进行，视频等待就绪后继续，安装耗时不占视频处理时限。支持下载重试、进度诊断、缓存完整性检查、损坏修复和卸载取消清理。

Linux x64/ARM64 使用无动态加载器的构建，适配 Alpine；Windows x64、macOS x64/ARM64 也提供对应下载。附 FFmpeg 与静态构建来源和原许可。
