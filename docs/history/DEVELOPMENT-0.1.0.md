## 存储和协议限制

Minato SQLite 的 `set()` 先读后写，不能直接当成 SQL 条件更新。当前使用插件进程内串行事务保证认领与审计共同成功；失败时事务回滚。**只验证单 Koishi 进程的 SQLite**，包括两个 Store 并发实例；不声称实现跨进程 sql.js 共享文件审批。

请求/事件通知都有持久化状态。发送失败/超时不会盲目重试；请求可通过列表与编号处理。密集事件超过详细队列容量时合并数量，因此超限部分不保留逐条明细。普通事件未做按事件类型单独配置路由，当前路由由 Bot 上下文、来源管理群和通知群决定。

OneBot `download_file` / `upload_group_file` / `upload_private_file` 属于扩展。模拟验证了官方适配器调用，尚未核实用户安装的 SnowLuma 版本是否按同样方式处理。Node 进程被强制杀死后的旧媒体工作目录未自动回收，需停机后人工清理。

## 依赖审计

首次 `npm audit --omit=dev` 遇到 socket hang up；第二次成功取得审计结果，返回非零是因为 **10 个 moderate，0 high，0 critical**。条目沿 Koishi 的 `@cordisjs/plugin-http → file-type` 依赖链传播，原始通告为 [GHSA-5v7r-6r5c-r473](https://github.com/advisories/GHSA-5v7r-6r5c-r473)，涉及畸形 ASF 解析可能无限循环。

新增直接运行依赖 `https-proxy-agent`、`ipaddr.js`、`json5` 没有出现在这次通告列表。未执行 `npm audit fix --force`，未降级/更改用户指定 Koishi 基线，也不能据此声称宿主不存在漏洞。插件媒体检查自行识别签名，视频另经 ffprobe；这不等于修复宿主依赖链。

| 首轮 TypeScript 的可选 Session 字段、guard 返回值、联合指令回调参数冲突 | 在入口检查身份，明确函数返回类型与回调参数；三个包构建通过 |

| 卸载后抑制回复导致 music job 缺少 undefined 返回类型 | 扩展类型并重建，取消/过期测试通过 |
| SQLite 普通 set 并非原子条件认领 | 改成事务与串行状态写入；20 并发和审计失败回滚通过 |
| 原实现缺少审批最终审计，普通事件限流会静默丢失 | 最终结果/审计同事务；持久化有界事件队列和数量合并通过测试 |
| OneBot SenderError 的字段是 code，而非只有 retcode | 同时识别数值字段；官方适配器明确失败与断线未知测试通过 |
| 酷狗旧 mobilecdn 域名 HTTPS 请求失败 | 只读验证 msearch.kugou.com 可用，更新搜索入口；再次实测搜索/歌词通过 |
